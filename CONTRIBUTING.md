# Contributing

Thanks for considering a contribution to a Kre8ivTech repository.

## Scope first

Open an issue before a large change. A person approves scope. A small fix can go straight to a pull request.

## Pull requests

- Keep the change focused on one thing.
- Follow the style already used in that repository.
- Say what changed and how you checked it.
- A person reviews and approves the merge.

## License

Contributions are under the license of the repository you contribute to.

## Security

Email security reports to [info@kre8ivtech.com](mailto:info@kre8ivtech.com). See [SECURITY.md](SECURITY.md). Do not open a public issue for a vulnerability.
