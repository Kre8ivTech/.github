# Security Policy

## Reporting a vulnerability

Report security issues by email to [info@kre8ivtech.com](mailto:info@kre8ivtech.com).

Please include:

- The repository, and the version or commit if you know it
- What the issue is and what it affects
- Steps to reproduce, if you have them

Do not open a public issue for a security report.

This is the default policy for public Kre8ivTech repositories that do not include their own `SECURITY.md`.
